# MeOS 需求说明（第一阶段）

## 一句话目标

做一个能在 VMware 里引导起来的最小操作系统，开机后屏幕上显示一行中文
「**Hi，我是meos，很高兴来到这个世界~**」，然后停机。

## 验收标准

| 项 | 标准 |
| --- | --- |
| 跑在哪 | VMware Workstation 虚拟机，x86 架构，BIOS 固件 |
| 怎么起 | 传统 BIOS + MBR 引导，光盘挂载启动，不用 UEFI、不用 GRUB |
| 看到什么 | 800x600 图形模式下，屏幕正中一行中文，白字黑底 |
| 之后怎样 | 停机保持画面，不重启、不报错 |
| 门槛 | **能看到这行字就算过**，不要求装到虚拟硬盘、不要求交互 |

## 明确不做的事

- 不做键盘输入、命令行、shell
- 不做文件系统、多任务、内存分页
- 不做 UEFI、不做 GRUB 之类的引导器
- 不追求多分辨率、多显卡兼容

## 技术选型

| 选择 | 理由 |
| --- | --- |
| NASM + 纯汇编 | 从零开始的最小系统，不引入 C 运行时和链接器 |
| 引导扇区 (MBR) + El Torito 光盘 | 用户指定的传统引导方式 |
| VBE 线性帧缓冲 (800x600x32) | 能直接往显存写像素，画中文最省事 |
| 32 位保护模式 | 为后续阶段（中断、内存管理）打好底子 |
| 自渲染点阵字模 | 系统没有字库，中文得自己烤成点阵塞进内核 |

## 运行环境

- VMware Workstation 17.6，`mkisofs.exe` 直接用它自带的
- NASM 汇编器
- Python 3 + Pillow（渲染字模、打包镜像）
- 开发机是 Windows + PowerShell

## 交付物

```
build\meos.iso      可直接挂进 VMware 启动的光盘镜像
build\meos.vmx      配套虚拟机配置
build\meos.img      1.44MB 软盘镜像，BIOS 也能直接引导
src\                全部源码
tools\              构建与验证脚本
```

## 里程碑

| 编号 | 内容 | 状态 |
| --- | --- | --- |
| M0 | 引导扇区跑起来，BIOS 能打印开机信息 | 已完成 |
| M1 | 内核进入 32 位保护模式，屏幕画出中文后停机 | 已完成 |
| M2 | 键盘中断 + 简易命令行 | 未开始 |
| M3 | 内存管理、简单文件系统 | 未开始 |

## 无歧义确认过的点

- 「系统能够安装」在本阶段解释为「能挂载 ISO 引导并跑起来」，不要求写入虚拟硬盘
- 「界面提示」在本阶段就是屏幕上的一行字，不要求图形界面框架
- 停机要停得住：不能让 VMware 报「客户机操作系统已禁用 CPU」，也不能让虚拟机复位
