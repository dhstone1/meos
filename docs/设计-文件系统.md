# MeOS 文件系统设计

> 第四阶段：为 MeOS 添加一个简单文件系统（SFS）。
> 目标：在已有的图形终端 + 网络栈之上，让内核能从内存或虚拟磁盘上读写文件，并提供新命令来操作它们。

## 0. 设计原则

1. **最小可运行**（MVP）—— 不做碎片整理、不做日志、不做目录嵌套、不做权限。
2. **平铺目录** —— 所有文件在同一根目录下，无子目录。
3. **固定块大小** —— 512 字节（和软盘扇区一致）。
4. **内存优先** —— 第一阶段文件数据直接编译进内核 payload，无需磁盘 I/O。
5. **解耦** —— 不依赖现有网络和显存驱动，在主循环同步上下文中完成。

## 1. 内存布局

| 地址区间 | 用途 | 大小 |
| --- | --- | --- |
| 0x8000 - 0x10000 | 内核代码+数据+字模 | ~32KB |
| 0x10000 - 0x22FFF | 网络缓冲区（e1000 环+包缓冲） | ~76KB 不变 |
| 0x23000 - 0x24000 | SFS 超级块 | 512B |
| 0x24000 - 0x2C000 | SFS FAT | 32KB（1024 条目） |
| 0x2C000 - 0x7BFFF | 文件数据缓存 | ~320KB |
| 0x7C000 | 内核栈顶 | — |

NIC 区域（0x10000-0x22FFF）和栈顶（0x7C000）均保持不变。

## 2. SFS 磁盘格式

### 2.1 超级块（512B，加载到 0x23000）

| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0x00 | 4 字节 | sf_magic | 魔数 0x5346534D（SFSM） |
| 0x04 | 4 字节 | sf_version | 版本号（当前 1） |
| 0x08 | 4 字节 | sf_block_size | 块大小，固定 512 |
| 0x0C | 4 字节 | sf_total_blocks | 总块数（内存模式填 0） |
| 0x10 | 4 字节 | sf_file_count | 当前文件数 |
| 0x14 | 8 字节 | sf_reserved | 保留 |
| 0x1C - 0x1FF | 484 字节 | 填充 0 | — |

### 2.2 FAT 条目（32 字节/条，最多 1024 个文件）

| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0x00 | 8 字节 | fe_name | 文件名 ASCII，不足补 0 |
| 0x08 | 4 字节 | fe_size | 文件大小（字节） |
| 0x0C | 4 字节 | fe_data_off | 数据在缓存区中的偏移 |
| 0x10 | 4 字节 | fe_blocks | 占用的块数 |
| 0x14 | 4 字节 | fe_attr | 属性（bit0=只读） |
| 0x18 | 8 字节 | fe_reserved | 保留 |

文件名约束：最长 8 个 ASCII 字符（a-z A-Z 0-9 _ -），区分大小写。

## 3. 内核新增常量

```nasm
; ---- 文件系统常量 ----
SFS_SUPER_ADDR    equ 0x23000
SFS_FAT_ADDR      equ 0x24000
SFS_FAT_MAX       equ 1024
SFS_FAT_SIZE      equ 0x8000         ; 32KB
SFS_DATA_CACHE    equ 0x2C000
SFS_CACHE_SIZE    equ 0x50000        ; 320KB
SFS_MAGIC         equ 0x5346534D

; ---- 超级块偏移 ----
SF_MAGIC          equ 0x00
SF_VERSION        equ 0x04
SF_BLOCK_SIZE     equ 0x08
SF_TOTAL_BLOCKS   equ 0x0C
SF_FILE_COUNT     equ 0x10

; ---- FAT 条目偏移 ----
FE_NAME           equ 0x00   ; 8 字节
FE_SIZE           equ 0x08
FE_DATA_OFF       equ 0x0C
FE_BLOCKS         equ 0x10
FE_ATTR           equ 0x14

; ---- 错误码 ----
FS_OK             equ 0
FS_ERR_NOT_FOUND  equ 1
FS_ERR_FULL       equ 2

; ---- 诊断块扩展 ----
D_FS_READY        equ 0x190
D_FS_FILES        equ 0x194
D_FS_LASTERR      equ 0x198
```

## 4. 内核新增过程

### 4.1 fs_init（shell_start 之前调用）

1. 检查 SFS_SUPER_ADDR 处的 sf_magic 是否为 SFS_MAGIC
2. 不匹配则 fs_ready = 0，系统照常启动
3. 匹配则读取 sf_file_count，设置 fs_ready = 1
4. 写 D_FS_READY 和 D_FS_FILES

### 4.2 fs_find

遍历 FAT 区比对 fe_name。

```
输入: ESI = 文件名（0 结尾 ASCII）
输出: EAX = FAT 条目地址 / 0（未找到）
```

### 4.3 fs_read

```
输入: ESI = 文件名，EDI = 目标地址
输出: EAX = 读取的字节数（0 = 未找到）
```

1. fs_find 定位 FAT 条目
2. 从 SFS_DATA_CACHE + fe_data_off 拷贝 fe_size 字节到 EDI
3. 返回 fe_size

## 5. 新命令

### 5.1 ls

遍历 FAT，打印文件名和大小。

```
meos> ls
README             1024
HELLO               512
```

### 5.2 cat <文件名>

截取参数，fs_read 读入缓存，con_puts 输出。

```
meos> cat README
Welcome to MeOS!
```

## 6. 预置文件数据（编译进内核）

在 kernel.asm 末尾添加。开机后 fs_init 直接从内存中加载。

```nasm
; ---- 预置文件系统数据 ----
fs_embedded_super:
    dd SFS_MAGIC
    dd 1               ; version
    dd 512             ; block_size
    dd 0               ; total_blocks
    dd 2               ; file_count
    dd 0, 0            ; reserved
    times 484 db 0

fs_embedded_fat:
    ; README
    db "README", 0, 0, 0
    dd fs_embed_file1_end - fs_embed_file1_data
    dd fs_embed_file1_data - fs_embed_data_start
    dd 0, 0, 0, 0
    ; HELLO
    db "HELLO", 0, 0, 0
    dd fs_embed_file2_end - fs_embed_file2_data
    dd fs_embed_file2_data - fs_embed_data_start
    dd 0, 0, 0, 0
    times 32 * (SFS_FAT_MAX - 2) db 0

fs_embed_data_start:
fs_embed_file1_data:
    db "Welcome to MeOS!", 13, 10
    db "This is the built-in readme file.", 13, 10
    db "Commands: help, ver, echo, cls, ls, cat, ping, net", 13, 10
fs_embed_file1_end:
fs_embed_file2_data:
    db "Hello from the MeOS file system!", 13, 10
fs_embed_file2_end:
```

## 7. 命令分发改动

```nasm
    ; --- ls ---
    mov esi, line_buf
    mov edi, cmd_ls
    call str_eq
    test eax, eax
    jz .try_cat
    call cmd_do_ls
    jmp .done

    ; --- cat ---
    mov esi, line_buf
    mov edi, cmd_cat
    mov ecx, 3
    call str_n_eq
    test eax, eax
    jz .unknown
    cmp byte [line_buf + 3], ' '
    jne .unknown
    mov esi, line_buf + 4
    call cmd_do_cat
    jmp .done

cmd_ls     db "ls", 0
cmd_cat    db "cat", 0
```

注：cat 和 echo 都是 4 字符前缀，分发顺序确保互斥。
